# Moments and hero objects

P1 (the picture holds the data) is worth more than any other pillar, and it is
the one AI skips. This file is how to find the hero for any app.

---

## 1. Find the moments first

A hero encodes *a state*, so you need the states. For the core screen, list
3–6 moments and the one fact each needs in one second.

Ways to find moments when the app has no obvious timeline:

| Axis | Moments |
|---|---|
| **Time to an event** | long before · soon · now · during · just after |
| **Progress** | not started · early · halfway · nearly · done · overdone |
| **Quantity** | plenty · comfortable · running low · out · over budget |
| **Streak / habit** | fresh · on track · at risk tonight · broken · restored |
| **Time of day** | morning · midday · evening · night (light, palette, copy shift) |
| **Place** | at home · commuting · at the venue · away |
| **Social** | alone · invited · others joined · everyone's here |
| **First run** | empty · first item · populated |

Write the table (moment → need → hero fact). If two moments need the same
fact, merge them. If the screen looks identical in every moment, P7 is 0.

---

## 2. The three tests (every hero must pass all three)

1. **Delete-the-numbers test.** Hide every number and label. Can you still read
   the state? (Jar half full: yes. A smiling plant mascot: no.)
2. **Glance test.** Understood in one second by someone who has never seen the
   app. If it needs a caption to explain the metaphor, it fails.
3. **Change test.** It visibly changes when the data changes, and the change can
   be animated (the jar fills as you add, the wedge shrinks as time passes, the
   house's lights go out as the routine completes).

Bonus test, **the screenshot test**: would someone screenshot this moment to
share it? The best heroes double as distribution.

**Run the first two, do not imagine them.** You know what the picture means,
so your own answer is worthless. The audit writes every screen with its words
and numbers removed (`blind/notext-NN.png`); a reader who has never seen the
brief says what the picture tells them (audit.md §3). P1 scores 1 only where
that reader gets the state roughly right.

---

## 3. Seven hero modes

The hero does not have to be an illustration. Across top-tier work there are
seven ways to make the picture carry the data. Pick the mode that fits the
product and the assets you can truly produce.

| Mode | What it is | Reference patterns | Best for |
|---|---|---|---|
| **Scene** | An illustrated place or situation whose state is the data | A night house whose lit windows track a bedtime routine; a train window showing where you are on the route | Routines, travel, journeys, ambient status |
| **Object** | One physical thing, drawn or rendered, filled or marked by the data | A coin jar filled to the money left; a station clock with a wedge of minutes left; a plant pot with a soil-moisture line | Budgets, timers, quantities, care |
| **Artifact** | The product's output as a real-world printed or made thing | A run turned into a till receipt; a ticket with perforation and a seal; a holographic card that tilts | Records, purchases, achievements, cards |
| **Instrument** | A tool you read or operate: dial, ruler, gauge, meter, wheel | A tick-ruler slider for distance; a vertical progress ruler down the screen edge for a training plan; a recorder with a speaker grille and hardware keys | Input, setup, measurement, media control |
| **Chart-as-art** | Data visualisation drawn with the care of an illustration | A radial line chart of a fund's holdings; a solar-noon arc across a sky gradient; a heatmap on a pitch | Finance, analytics, health, sport |
| **Material** | A 3D or tactile object (glass, clay, liquid, chrome) that reacts to state or touch | A breathing liquid orb for an AI assistant; glass rings to pick an appearance; clay stars for completed tasks | Assistants, personalisation, celebration |
| **Number + atmosphere** | One giant figure in a lit, textured field | `$400` in a serif glow on a star field; `16 KM` with a ruler; `€137.60` with small decimals | Money moves, goals, single-metric moments |

Photography and collage are a material, not a mode: a strip of the user's own
leaf photos, polaroids on a sky, an editorial outfit. Use real photos only when
you can actually get them (user assets, verified sources, generation if
allowed). Never grey boxes or broken URLs.

## 4. The catalog: 60+ mappings

Use these to calibrate, not to copy. The right hero comes from *this* product's
data and culture.

**Money**
- Budget left this week → a jar of coins filled to the amount, ruler of daily spends up the side
- Savings goal → a glass filling toward a painted line; a stack of envelopes thickening
- Spending by category → stacked jars of different heights
- Bill due → a paper bill whose corner curls more as the date nears
- Cash sent/received → the note itself sliding across, `$400` with serif glow
- Card → the physical card, tilting, with material (holo, metal, wood)
- Investments → radial line chart, each holding a coloured spoke

**Fitness and health**
- Run / long run → the track oval in concentric lines; the route line
- Training plan → a vertical progress ruler down the edge; a week strip of distances
- Strength workout → plates on a barbell (the weight literally drawn)
- Steps → a path of footprints to a landmark
- Water intake → a glass or bottle with ml ticks, liquid at the level
- Sleep → a house at night, lights going out; a moon phase for sleep debt
- Heart rate → a beating heart shape with the number inside; a cardiogram line drawn as art
- Meditation / breath → a tide or water level rising and falling with the breath
- Medication → a weekly pill organiser with compartments emptied
- Cycle tracking → a calendar of soft shapes; a garden that changes through the month

**Habits and productivity**
- Streak → a chain of links, the next one open; a calendar of stamps
- Daily routine → a lit house (the night-house pattern); a sun arc for the day
- Focus timer → a clock wedge; sand in an hourglass
- Task list done → clay stars or stamps collected
- Inbox zero → a desk tray emptying
- Reading → a book whose bookmark sits at the real page depth
- Journal → a notebook page with today's ink; a postcard from the day
- Calendar day → sunlight across the day with meetings as shadows

**Travel and place**
- Departure → a station clock with minutes-left wedge; a split-flap board with your row lit
- Where to stand → the train or plane side view with *your* door lit
- On the way → the window view of what's outside now
- Arrival → the destination skyline at the real time of day
- Ride / delivery → the courier on the street, the door at the end
- Parking → the meter with time remaining; your car in its bay
- Hotel → the key card; the room door with its number
- Navigation → time and distance remaining over a map (CarPlay pattern)

**Food and home**
- Recipe step → the pan or oven with a timer dial; the plate assembling as steps complete
- Groceries → a bag filling; a fridge shelf with gaps where items run low
- Plant care → the plant itself, huge, bleeding off the edge; the pot's soil line
- Smart home → a floor plan with lit rooms; the thermostat dial
- Pet care → the bowl, filled to the last feed; the lead by the door for the walk

**Learning and culture**
- Language lesson → a culturally right object (an Italian playing card for "Quanto le devo?"; a café table for ordering)
- Course progress → a trail with campsites as checkpoints
- Flashcards → the card itself, flipping
- Music practice → the instrument's neck with the frets you have learned lit
- Podcast / audio → a tape reel showing tape remaining; a vinyl sleeve
- Photo memories → polaroids on a sky; a collage

**Social and events**
- Event → the table set, chairs filled by those who said yes
- Group goal (relay) → runners' avatars along a shared track; the baton position
- Messages / unread → letters in a mail slot
- Dating / matching → two paths converging on a map

**Assistants and tools**
- AI assistant idle/thinking/speaking → a liquid or glass orb that breathes, ripples, speaks
- Voice note → a recorder with a level meter and hardware keys
- Scanner → the document itself lifting off the desk
- Weather → the window: what the sky actually looks like now

**Commerce**
- Product → the product as the hero object, editorial crop
- Cart → the bag filling
- Order status → the parcel's journey as a strip: shelf, van, porch
- Loyalty → a punch card with holes punched

## 5. Failure modes

| Failure | Why it fails | Instead |
|---|---|---|
| A mascot or character that smiles at you | Decoration; never encodes state | Draw the *thing*, not a friend |
| A stock illustration of a person using a phone | Says nothing about this user's data | The object the data is about |
| A metaphor that needs a caption | Fails the glance test | Pick a more literal object |
| The same picture in every state | Fails the change test (P1 and P7) | Bind the picture to the data |
| A tiny icon-sized hero | Fails coverage (P2) | 30–50% of the screen; bleed it |
| Several heroes fighting on one screen | No first read | One hero per screen; supporting art stays small |
| A hero on settings or long forms | Misplaced richness | Heroes where people look for status (SKILL.md §6) |
| A hero and a giant number on a library, a feed or a chat | The glance skeleton on a screen with another job; the content is pushed off | Structure from the job (anatomy.md §1): the rows, the items or the messages lead |
| A drawn scene the code cannot carry | Clean primitives read as clip art and cap the screen at 7–8 | Another mode: a chart, an instrument, type or an artifact reaches 9 in code |
| A beautiful hero, invisible data | Art for art's sake | Put the number on, in, or next to the object (a ruler on the jar, a marker on the track) |

## 6. Binding the hero to data (make it real)

A hero is only P1 if it is computed from the data. In code:

```js
// jar fill: liquid height from remaining / budget
const fill = Math.max(0, Math.min(1, remaining / budget));
liquid.setAttribute('y', jarTop + jarHeight * (1 - fill));
liquid.setAttribute('height', jarHeight * fill);

// clock wedge: from "now" to departure, in minute-hand degrees
const a0 = nowMinutes * 6, a1 = departMinutes * 6;           // 0° = 12 o'clock
const p = (deg) => [cx + r * Math.sin(deg * Math.PI / 180), cy - r * Math.cos(deg * Math.PI / 180)];
const [x0, y0] = p(a0), [x1, y1] = p(a1);
wedge.setAttribute('d', `M${cx} ${cy} L${x0} ${y0} A${r} ${r} 0 ${a1 - a0 > 180 ? 1 : 0} 1 ${x1} ${y1} Z`);

// lit windows: one window per routine step, lit while the step is not yet done
windows.forEach((w, i) => w.classList.toggle('lit', i >= stepsDone));
```

Then animate the transition between states (spring or 600–1100 ms
ease-in-out), so the change test is visible, not implied.
